# Zento Bot v2

نسخه پیشرفته‌تر ربات زنتو با Flask + SQLite.

## امکانات
- منوی اصلی
- پروفایل
- امتیازات
- جایزه روزانه (+5)
- راهنما
- پشتیبانی
- آمار مدیر
- ذخیره کاربران در SQLite
- endpoint سلامت `/health`

## Railway Variables
`BOT_TOKEN`, `ZENTO_API_BASE=https://zento.up.railway.app/api/bot`, `ADMIN_ID`, `ENABLE_KEYBOARD=false`

Webhook: `https://YOUR-RAILWAY-DOMAIN/webhook`

تست: `/start` `/profile` `/points` `/daily` `/help` `/support` `/stats`
