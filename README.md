# Zento Bot v3 — Professional Glass Menu

نسخه حرفه‌ای ربات زنتو با منوی شیشه‌ای (Inline Keyboard).

## امکانات
- منوی شیشه‌ای حرفه‌ای
- دکمه‌های چندمرحله‌ای
- پروفایل
- امتیازات
- جایزه روزانه (+5)
- راهنما
- پشتیبانی
- درباره ربات
- آمار مدیر
- SQLite
- Webhook
- پشتیبانی از callback button

## Railway Variables
BOT_TOKEN
ZENTO_API_BASE=https://zento.up.railway.app/api/bot
ADMIN_ID
DB_PATH=bot.db

Webhook:
https://YOUR-RAILWAY-DOMAIN/webhook

تست:
`/start`
`/profile`
`/points`
`/daily`
`/help`
`/support`
`/about`
`/stats`

نکته:
این نسخه از `inline_keyboard` استفاده می‌کند تا دکمه‌ها داخل پیام نمایش داده شوند.
